# profeya-appPetSitter
Descripción del proyecto

PetSitter es una plataforma web pensada para conectar dueños de mascotas con personas que ofrecen servicios de cuidado de mascotas.

El proyecto busca resolver la dificultad que tienen muchos dueños para encontrar cuidadores confiables cuando necesitan ausentarse por trabajo, viajes o situaciones personales.

Los principales usuarios son:
Dueños de mascotas que necesitan servicios de cuidado.
Cuidadores de mascotas que desean ofrecer sus servicios.

Funcionalidades actuales:
Landing page principal.
Registro de profesores/cuidadores.
Inicio de sesión de profesores/cuidadores.
Navegación básica entre páginas.
Diseño inicial de la interfaz web.
